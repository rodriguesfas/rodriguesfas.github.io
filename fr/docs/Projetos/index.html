Projetos em destaque

Revisei meus repositórios e as organizações em que participo (~75 repos públicos sob rodriguesfas, dezenas em orgs). Abaixo ficam os que merecem destaque: impacto, publicação, produto, aviação e ferramentas que ainda mantenho. O restante continua nas categorias do menu.

Pesquisa e tecnologia assistiva​

DeepNLPF​

Framework do mestrado (UFPE/CIn) para integrar análise linguística e anotação semântica de documentos. Publicado no LREC 2020. Código e plugins na org deepnlpf.

DAVI​

Dispositivo de apoio a pessoas com deficiência visual — TCC na UniLeão. Wearable assistivo; org Dispositivo-DAVI.

ConjugAI​

Projeto do AAC AI Lab (pesquisa de doutorado): conjugação e apoio à comunicação aumentativa e alternativa. Parte do ecossistema ainda é privada (modelos, datasets e experimentos).

Produto​

Octor​

Plataforma de gestão para clínicas e consultórios (prontuário, agenda, financeiro, automações). O código de produto vive em repositórios privados da org 0ctor — citei aqui porque é o trabalho profissional de maior escala que mantenho hoje. Detalhe em Startups → Octor.

onBible​

PWA da Bíblia sagrada. Org onbible.

Aviação — Prime Flight​

Wrappers Python públicos para dados e serviços aeronáuticos no Brasil (e afins):

ProjetoO que faz
aiswebWrapper da API AISWEB (DECEA)
rabRegistro Aeronáutico Brasileiro (RAB)
redemetWrapper REDEMET
jetphotosWrapper do site Jet Photos
civ-dbWrapper CIV e Diary Board

Site da org: primeflight.github.io.

Hardware, visão e IoT​

Reconhecimento facial — Arduino + Processing + OpenCV​

Visão computacional embarcada: detecção facial com Arduino, Processing e OpenCV. Um dos repositórios públicos com mais interesse na conta.

Sonar Arduino + Processing​

Radar ultrassônico: Arduino lê obstáculos e o Processing desenha o mapa.

Andruino Bluetooth​

App Android para falar com Arduino via Bluetooth — útil em aulas e protótipos de robótica.

Hidropoino​

Horta hidropônica inteligente. Finalista MOCINN/MOCICA e credenciamento FENECIT.

MonokArduino​

Tema escuro estilo Monokai para o IDE do Arduino.

Bibliotecas Arduino​

  • LM35 — sensor de temperatura
  • DMPH L298N — driver de motor ponte H

Ferramentas​

nitrosense​

Clone não oficial do NitroSense para notebooks Acer Nitro no Linux (GTK4). Testado no ANV15-51.

git-board​

Painel leve sobre atividade Git.

SafeKeepDB​

Backup automatizado de MySQL com notificações e tratamento de erro.

Cron​

Cronômetro para provas de robôs solucionadores de labirinto (olimpíadas / torneios).

JResistor​

Calculadora gráfica de resistores.

APIs pequenas​

  • holidays — feriados brasileiros
  • places — localidades no Brasil
  • qrcode — geração de QR Code
