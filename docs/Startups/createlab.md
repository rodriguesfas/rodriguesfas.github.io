# CreateLab

Fui co-fundador da CreateLab (2019): educação tecnológica com material didático de robótica para crianças e adolescentes, e capacitação de professores.

Elaborei o material, formei professores e construí a distribuição digital para escolas — incluindo a área de compra de kits.

> Competências: professor, instrutor, escritor, Arduino, LEGO, C/C++, PHP, JavaScript, Node.js, WordPress, HTML, CSS, Linux, Windows, Laravel, Angular.
