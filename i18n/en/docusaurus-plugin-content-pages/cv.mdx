## Professional experience

### Octor — Co-founder, Computer Scientist & Software Engineer
**[octor.com.br](https://octor.com.br/)** (formerly [qHoras](https://qhoras.com.br/)) · present

I am currently a software engineer and computer scientist at [Octor](https://octor.com.br/), a startup focused on software for managing clinics, medical practices, and healthcare professionals. Octor’s mission is to deliver technology that streamlines workflows, improves patient-care efficiency, and simplifies practice management.

I work across the full development cycle — from conception and architecture to delivery and maintenance. I also integrate external APIs, optimize platform performance, and build data-analysis algorithms that provide detailed insights to users. I apply machine learning and data science techniques for recommendations and informed decisions in patient care.

**AI / LLM / NLP contributions (in production)**
- Clinical LLM platform (**Sereia**): Rust API + Redis queues + GPU workers (Whisper speech-to-text; vLLM instruct model for chat/agent) with clinical tools (ICD, TUSS, ANVISA formulary, knowledge)
- Decoupled **transcription** (ASR) service with async jobs and Whisper on GPU
- CPU **typed-decision** engine (`platform-decide`): intent classification, scoring, and NLI (yes/no with confidence) for SDR, chat, CRM, tickets, and clinical-risk gating — no free-form generation
- Integration and ops for **Laya** (System One / multilingual typed decisions) in internal flows (e.g. ticket priority)
- WhatsApp intake orchestration (**SDR AI**): classify with decide/NLI, reply with controlled text, sync CRM — no clinical hallucination from generative LLMs
- **Text extraction** (PDF/DOCX/image) with cascaded OCR for CRM and migrations
- Document chat (PDF) and model experimentation for product

**Backend & product**
- Microservices and APIs for scheduling, EHR, billing, inventory, confirmations, and automations
- Telemedicine, intelligent EHR, and process automation
- WhatsApp, CRM, and external integrations; API-key auth; OpenAPI documentation
- Self-hosted deploy and operations (Docker, bare metal, GPU workers, internal VPN)

> **Skills**: Software Engineering, Backend Development, Microservices, APIs, Data Analysis, Machine Learning, LLMs, NLP/NLI, ASR, OCR, Python, Rust, FastAPI/Actix, Redis, vLLM, Whisper, Transformers, Laya, PHP, MySQL, SQLite, Docker, Linux, OpenAPI, PaaS
