Octor — Co-fundador, Cientista da Computação e Engenheiro de Software​

octor.com.br (antes qHoras) · atual

Atualmente sou engenheiro de software e cientista da computação na Octor, startup focada no desenvolvimento de software para gestão de consultórios, clínicas médicas e profissionais de saúde. Na Octor, a missão é oferecer soluções tecnológicas que otimizam o fluxo de trabalho, melhoram a eficiência no atendimento ao paciente e facilitam a gestão de práticas de saúde.

Trabalho no ciclo completo de desenvolvimento, desde a concepção e arquitetura até a entrega e manutenção de funcionalidades. Também sou responsável por integrar sistemas com APIs externas, otimizar o desempenho da plataforma e desenvolver algoritmos de análise de dados para fornecer insights detalhados aos usuários. Aplico técnicas de machine learning e ciência de dados para recomendações e decisões informadas no cuidado aos pacientes.

Contribuições em IA / LLM / PLN (em produção)

  • Plataforma clínica de LLM (Sereia): API em Rust + filas Redis + workers GPU (Whisper para áudio→texto; vLLM com modelo instruct para chat/agente), com tools clínicas (CID, TUSS, formulário ANVISA, knowledge)
  • Serviço de transcrição (ASR) desacoplado do agente, com jobs assíncronos e modelos Whisper em GPU
  • Motor de decisão tipada em CPU (platform-decide): classificação de intenção, scoring e NLI (sim/não com confiança) para SDR, chat, CRM, tickets e gate de risco clínico — sem gerar prosa
  • Integração e operação do motor Laya (System One / decisões tipadas multilíngue) em fluxos internos (ex.: priorização de tickets)
  • Orquestração de atendimento WhatsApp (SDR AI): classifica com decide/NLI, responde com textos controlados e sincroniza CRM — sem alucinação clínica por LLM generativo
  • Extração de texto (PDF/DOCX/imagem) com OCR em cascade para alimentar CRM e migrações
  • Chat com documentos (PDF) e experimentação de modelos para produto

Backend & produto

  • Microsserviços e APIs para agenda, prontuário, financeiro, estoque, confirmações e automações
  • Telemedicina, prontuário eletrônico inteligente e automação de processos
  • Integrações com WhatsApp, CRM e sistemas externos; auth por API key; documentação OpenAPI
  • Deploy e operação em ambiente próprio (Docker, bare metal, GPU workers, VPN interna)

Competências: Engenharia de Software, Desenvolvimento Backend, Microserviços, APIs, Análise de Dados, Machine Learning, LLMs, PLN/NLI, ASR, OCR, Python, Rust, FastAPI/Actix, Redis, vLLM, Whisper, Transformers, Laya, PHP, MySQL, SQLite, Docker, Linux, OpenAPI, PaaS
